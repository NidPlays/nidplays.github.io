Every blog needs a first post, and this is mine.

## why a blog

My [portfolio](/) shows *what* I've made — this blog is for the *how* and the
*why*: build notes, design decisions, photography trips, and things I learn
along the way that are too long for a commit message.

## how it's built

This site is a two-part setup living in a single repo:

- The **portfolio** at the root is a [React](https://react.dev) +
  [Vite](https://vite.dev) + TypeScript app, built around the photographs.
- The **blog** you're reading is generated by
  [Zensical](https://zensical.org), the static site generator from the
  Material for MkDocs team — plain Markdown in, fast static pages out.

Both are built together and deployed as one site. Posts are just Markdown
files, which means writing a new one looks like this:

```bash
cd blog/docs/posts
$EDITOR my-next-post.md
git commit -am "post: my next post"
git push   # CI builds and deploys the rest
```
